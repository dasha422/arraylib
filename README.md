# ArrayLib — библиотека операций над массивами

## Описание проекта

ArrayLib — кроссплатформенная динамическая библиотека на языке C++ для выполнения математических операций над массивами целых чисел.

Проект разработан в рамках лабораторной работы № 2.

## Реализованные функции

1. `arr_sum` — вычисление суммы элементов массива.
2. `arr_max` — поиск максимального элемента.
3. `arr_min` — поиск минимального элемента.
4. `arr_count_positive` — подсчёт положительных элементов.
5. `arr_count_negative` — подсчёт отрицательных элементов.
6. `arr_count_zero` — подсчёт нулевых элементов.
7. `arr_product` — вычисление произведения элементов.
8. `arr_average` — вычисление среднего арифметического.
9. `arr_median` — вычисление медианы массива.

## Вариант 1. Температура воздуха

Программа обрабатывает среднесуточные температуры воздуха за 30 дней.

Она вычисляет:
- среднюю температуру;
- максимальную температуру;
- минимальную температуру;
- количество морозных дней;
- медиану температур.

Для вычислений используются функции динамической библиотеки ArrayLib.

### Запуск программы варианта 1

```bash
cmake -S . -B build
cmake --build build
./build/variant_01
```

После запуска необходимо ввести 30 значений температуры.
